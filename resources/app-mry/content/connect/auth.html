    Preset Verification Message

    Send users a one-time password (OTP) or verification code with:
    - Fixed preset text: {VERIFICATION_CODE} is your verification code.
    - Security disclaimer (optional): For your security, do not share this code.
    - Expiration warning (optional): This code expires in {NUM_MINUTES} minutes.

  • ○

    Multiple Authentication Methods

    - One-Tap Autofill
    Users tap the autofill button, opening your app with the code pre-filled automatically.
    - Copy Code Authentication
    Users tap the copy code button, storing the code on the clipboard for manual pasting.
    - Zero-Tap Authentication
    The WhatsApp client broadcasts the code, and your app captures it instantly, eliminating manual entry.
